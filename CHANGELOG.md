First public distribution of the bounded research core.

- Publish an explicit-root HCD event ledger with idempotency, immutable first direction, owner/epoch checks, evidence expiry, and bounded storage.
- Keep plan/result acceptance separate and invalidate stale acceptance, ordinal distance, and quality after further correction.
- Publish caller-injected correction-pattern clustering, manual intervention markers, cross-task recurrence, and schema 3 reporting with D secondary.
- Preserve the distinction between model-label agreement, agent-relayed evidence, and user truth.
- Add deterministic TaskA/TaskB examples and synthetic regressions, with disabled integration profiles and an explicit public file allowlist.
- Document implementation lineage, concrete research directions, and the public/private boundary.

Actual records, personal runtime/configuration, native collectors, model training, automatic maintenance, live deployment, and cloud/MCP runtime are excluded. There are no earlier public tags or releases of this core. Real-user effectiveness and complete task coverage remain unverified.
